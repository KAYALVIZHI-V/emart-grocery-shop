## Project Description
E-MART Grocery Shop is a **React + Vite frontend project** built to simulate an e-commerce grocery website.  
Users can browse products, view details, and navigate through categories.

---

## Technologies Used
- **React**  
- **Vite**  
- **TypeScript**  
- **Tailwind CSS**  
- **shadcn-ui**  
- **React Router**  
- **Recharts** (for charts/graphs if any)
